すべての駒が同じ強さではありません。駒の価値は **点数** で比べます：

| 駒 | 価値 |
|---|---|
| ポーン | 1 |
| ナイト | 3 |
| ビショップ | 3 |
| ルーク | 5 |
| クイーン | 9 |
| キング | 計り知れない |

## 駒の交換

駒を取ったり交換したりするときは、点数を足して比べます。ナイト（3）とルーク（5）の交換は **得**、クイーン（9）とルーク（5）の交換は **損** です。

<Exercise kind="make-move" fen="4k3/8/8/1r1p4/8/2N5/8/4K3 w - - 0 1" answers="c3b5" explain="Nxb5：ルーク（5点）を取るほうが、ポーン（1点）を取るよりずっと得です。">
ナイトはルークもポーンも取れます。**一番得な取り方** を選びましょう。
</Exercise>

## 浮き駒

攻撃されていて **守られていない** 駒を「浮き駒」と言います。相手に浮き駒がないか、そして自分に浮き駒がないか、いつも確認しましょう！

<Exercise kind="make-move" fen="4k3/8/8/2b5/8/8/8/2R1K3 w - - 0 1" answers="c1c5" explain="Rxc5：黒のビショップは誰にも守られていないので、タダで取れます。">
黒のビショップが浮いています。**取りましょう**。
</Exercise>

<Callout type="tip">
**駒得している** ときは駒を交換して局面を単純にしましょう。**駒損している** ときは交換を避けましょう。
</Callout>

<Callout type="rule">
点数はあくまで目安です。よく働いている駒は、表の点数よりずっと価値があることもあります。
</Callout>
