Every square has a **name**: its file letter plus its rank number. The square on file **e**, rank **4** is called **e4**.

## Writing moves down

Chess players record games with **algebraic notation**. Each piece has a letter:

| Piece | Letter | Example |
|---|---|---|
| King | K | Ke2 |
| Queen | Q | Qh5 |
| Rook | R | Rd1 |
| Bishop | B | Bc4 |
| Knight | N | Nf3 |
| Pawn | _(none)_ | e4 |

A move = piece letter + destination square. **Nf3** means "knight to f3". Pawn moves just name the square: **e4**.

## Special symbols

- **x** — capture: _Bxc6_ (bishop takes on c6), _exd5_ (the e-pawn takes on d5).
- **+** — check, **#** — checkmate.
- **O-O** — kingside castling, **O-O-O** — queenside castling.
- **=Q** — promotion to a queen: _e8=Q_.
